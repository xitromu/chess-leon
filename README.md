# Шахматы с Леоном

Шахматная игра-обучалка для ребёнка 6 лет. Ведущий — хамелеон Леон, с ним друзья: геккон Малон, ёжик, черепашка,
попугай и аксолотль. Игра — один файл `index.html`, голосовые записи — папка `voice/`. Работает в браузере планшета,
телефона и компьютера; после скачивания голоса — и без интернета.

Ссылка: https://xitromu.github.io/chess-leon/

## Что внутри (версия 2.3)

- **100 уроков** разделами: клетки доски, знакомство с фигурами, правила (шах, мат, пат, рокировка, взятие на проходе),
  пешечный бой в три уровня, мини-игры (фигура против пешек), тактика (вилки, связка, сквозной удар, вскрытый и двойной
  шах), задачки (съешь и спаси, мат в 1, мат в 2), дебют, маты, эндшпили, викторины и партия с Леоном.
  Полный список — в `PLAN.md`.
- **Монетки:** за верный ответ с первой попытки — две, со второй — одна, за каждую новую звезду урока — пять, за победу в игре — приз. За ошибки монетки не отнимаются. Подарки и друзья вместе стоят 1675 монеток: с тратами на кормление этого хватает примерно на 80 уроков.
- **Подарки (18):** шарики, торт, сундук, кубок, медаль, гирлянда, барабан, музыкальная шкатулка, салют, конфетти,
  мыльные пузыри, волшебная палочка, краски (меняют цвет Леона), краски для доски, а в террариум — цветы, домик для друзей,
  гамак и ночник. Купленный подарок можно показывать или прятать.
- **Террариум:** 21 букашка за монетки. Летуны машут крыльями, лягушка и кузнечик прыгают, улитка, червячок и гусеница
  ползут, рыбка плавает в луже. Букашку съедает тот, к кому она ближе: Леон ловит языком, друзья подпрыгивают.
  Друзья покупаются здесь же; в урок Леон берёт одного из них. Банка с едой — два ряда, листается вбок.
  У каждой букашки свой звук, когда она выбегает из банки, и «хрум-хрум», когда её поймали.
- **Голос:** фразы читает запись Silero (голос aidar, темп 1,25): 1320 кусочков, 16 МБ. Записи берутся с сайта, а строка
  под кнопкой «Покормить» скачивает их на устройство, и тогда интернет для голоса не нужен. Если записи нет (нет сети и голос
  не скачан) — читает синтез устройства. Та же строка показывает, чем сейчас говорит игра. Клетки и числа склеиваются
  из отдельных записей («найди клетку» + «е четыре»).

## Как играть

Открыть ссылку в браузере. Монетки, звёзды и покупки хранятся в памяти браузера.

**iPad:** открыть ссылку в Safari, нажать строку голоса в меню, чтобы скачать записи, затем «Поделиться» → «На экран „Домой“».
Значок нужен, потому что Safari может стереть данные сайта, если его не открывать 7 дней. Запись звучит и при выключенном
звуке устройства (Safari 16.4+), громкость — кнопками планшета.

**Копия файла** (например, из Telegram) берёт записи с сайта: без интернета и скачивания читает синтезом устройства.

## Голос устройства

Нужен, только когда записи недоступны. Мужской голос на Android: «Настройки» → поиск «Синтез речи» → движок Google → русский → выбрать голос.

Если голоса нет (Huawei и другие планшеты без сервисов Google): поставить бесплатный **RHVoice**
(AppGallery, F-Droid, Google Play), скачать в нём русский голос (мужские — Aleksandr, Artemiy и др.), выбрать RHVoice
в «Специальные возможности → Синтез речи» и перезапустить браузер. Проверить голос — `tools/tts_check.html`.
Из встроенного окна Telegram игра не говорит — открывать в Chrome или Яндекс.Браузере.

## Файлы

| Путь | Что это |
|---|---|
| `index.html` | вся игра: правила шахмат, уроки, картинки, звук |
| `voice/` | записи голоса; имя файла — хеш текста (`vkey` в игре, `hkey` в `voice_tool.py`) |
| `sw.js` | служебный скрипт: страница открывается без интернета, при наличии сети берётся свежая |
| `PLAN.md` | план: уроки, облик, террариум, призы |
| `promo/` | программы промо-ролика: съёмка игры (`capture.py`), мультфильм (`story.js`), музыка (`music.py`), сборка (`render.py`); кадры и готовое видео в репозиторий не входят |
| `tools/` | сборка картинок (`build_art.py`, рисунки — Stable Diffusion XL, `make_art.py`), автопрогон уроков (`autorun.js`), проверка голоса устройства (`tts_check.html`), запись голоса (`voice_collect.py` собирает фразы, `voice_build.py` записывает новые, `voice_stress.txt` — ударения, `voice_test.py` проверяет все режимы) |
| `mockups/` | макеты оформления, по которым выбирали вид (не нужны для игры); исходные рисунки `mockups/art/` в репозиторий не входят; `mockups/sounds/` — образец звуков букашек |
